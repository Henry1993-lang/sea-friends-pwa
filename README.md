# わたしのミニ水槽 (sea-friends-pwa)

2さい向けの、文字なしで遊べる水の生きものアプリ(PWA)。スマホのChromeでURLを開き、「ホーム画面に追加」すると全画面・オフラインで使えます。データ(録音・進みぐあい)は端末の中だけに保存されます。

## v2(ためし版)

`v2/` フォルダに改良版があります(公開後は `…/sea-friends-pwa/v2/` で開けます)。元の版(このフォルダの直下)とは保存データ・録音・オフライン保存を分けているので、v2 を試しても元の版は変わりません。v2 を初めて開いたときだけ、元の版の進みぐあいと録音を写して始まります。

v2 で増えたこと(ミニ水槽):
- 水の中を指でさわる・なぞると、起きている生きものが寄ってくる
- 生きものを指でなでると喜ぶ
- 近くに来た生きもの同士があいさつする/なかまのそばで一緒に泳ぐ
- 端末をかたむけると、生きものとごはんがそっちへ流れる(保護者設定で切れる)
- 夕方(16〜19時)は水の色が夕焼けになる
- 生きものが 8 種ふえた(ペンギン・アザラシ・イルカ・ラッコ・マンタ・ジンベエザメ・チョウチョウウオ・カニ)
- ずかんで大きく見ているとき、同じなかまが下に並び、さわると切りかわる

元の版は枝 `original-v1.1.0` にも保存しています。
